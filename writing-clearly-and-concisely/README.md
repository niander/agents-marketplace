# writing-clearly-and-concisely

Editing help for the kind of writing someone sits down and reads: documentation,
design docs, reports, articles. Covers both what to do and what to avoid.

The skill loads a short set of core rules up front and points to larger reference
files that are read only when a task needs them.

## What it covers

- **Strunk's rules** — active voice, positive form, concrete language, omitting
  needless words, keeping related words together, emphatic word placement.
- **AI writing patterns** — puffery, empty "-ing" clauses, promotional adjectives,
  overused vocabulary, formatting excess.

## Bundled files

| File | Purpose |
| --- | --- |
| `SKILL.md` | Core rules, and when to reach for each reference |
| `elements-of-style/03-elementary-principles-of-composition.md` | Strunk on paragraph structure, active voice, concision |
| `signs-of-ai-writing.md` | Condensed field guide to AI writing tells |

Most tasks need only `03-elementary-principles-of-composition.md`.
